# 模型配置

如何在 new-api 中配置和管理 AI 模型。

## 可用模型

配置渠道后，系统会自动检测每个服务商的可用模型。你可以在 **模型** 页面查看和管理它们。

## 添加自定义模型

1. 进入 **模型** 页面（`/models`）
2. 点击 **添加模型**
3. 填写详细信息：

| 字段 | 说明 |
|---|---|
| 名称 | 模型的显示名称 |
| Model ID | 实际的模型标识符（如 `gpt-4o`） |
| 服务商 | 该模型属于哪个渠道/服务商 |
| 类型 | `chat`（对话）、`completion`（补全）、`embedding`（嵌入）或 `image`（图像） |
| 分组 | 限定给特定用户分组使用（可选） |
| 优先级 | 优先级越高的模型越先被尝试 |
| 权重 | 负载均衡权重（越高分配越多流量） |

## 模型分组

模型可以按分组管理，用于：

- **访问控制**：将特定模型限定给特定用户分组
- **负载均衡**：将流量分配到同一类型的多个模型
- **故障切换**：在主模型不可用时定义回退顺序

## Token 统计

每次模型调用的 Token 用量会自动记录并在看板中显示。你可以在 **概览 > 模型看板** 页面查看各模型的统计数据。

## 测试

添加模型后，使用 **Playground**（`/playground`）发送测试提示词，验证模型是否正常响应。
