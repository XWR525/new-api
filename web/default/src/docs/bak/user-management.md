# 用户管理

如何在 new-api 中创建和管理用户。

## 用户角色

| 角色 | 说明 |
|---|---|
| 管理员 | 完全的系统访问权限，可管理所有设置和用户 |
| 普通用户 | 标准用户，可创建 API Key 并发起请求 |

## 创建新用户

管理员可以在 **用户管理** 页面（`/panel/users`）创建新用户：

1. 点击 **创建用户**
2. 设置用户名和密码
3. 根据需要配置权限

## API Key

每个用户可以在 **API 密钥** 页面（`/keys`）创建自己的 API Key：

1. 点击 **新建密钥**
2. 为密钥命一个描述性名称
3. **立即复制并保存密钥**——之后将无法再次查看

密钥格式为 `sk-` 加上一段随机字符串。

## Token 用量追踪

每个用户的 Token 消耗独立统计。可在以下页面查看详细数据：

- **概览 > 用量概览**——整体使用趋势
- **概览 > 模型看板**——按模型的用量分解
- **使用日志**——逐次请求记录

## 自助注册

如果管理员启用了注册功能，新用户可以通过注册页面使用邮箱、GitHub OAuth 等方式自助注册。
