# 数据看板

了解分析和监控看板的使用方法。

## 用量概览（`/dashboard/overview`）

概览页面提供 API 使用情况的总体摘要：

| 卡片 | 说明 |
|---|---|
| 总用量 | 所有模型的 Token 消耗总量 |
| 总请求数 | API 调用累计次数 |
| 24 小时消耗 | 最近 24 小时的 Token 用量 |
| 历史用量 | 长期使用趋势 |

## 模型看板（`/dashboard/models`）

模型页提供按模型维度的分析：

| 卡片 | 说明 |
|---|---|
| 总数 | 各模型的 API 调用次数 |
| 总 Token 数 | 各模型的 Token 消耗量（以 k = 1,000 为单位显示） |
| 平均 RPM | 每分钟请求数 |
| 平均 TPM | 每分钟 Token 数 |

**消耗分布** 图表展示了不同模型之间的 Token 用量分布。

## 使用日志（`/usage-logs`）

每次 API 请求的详细记录：

| 列 | 说明 |
|---|---|
| 时间 | 请求发起时间 |
| 用户 | 发起请求的用户 |
| 模型 | 使用的模型 |
| 渠道 | 处理请求的上游服务商 |
| 类型 | 请求类型（对话、嵌入、图像等） |
| Token | 输入/输出 Token 数量 |
| 费用 | Token 总数 |
| 状态 | 成功或错误 |

使用顶部的筛选条件可按日期范围、用户、模型或渠道缩小查询范围。
